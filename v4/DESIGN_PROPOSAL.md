# AI Company v4 - 完整架构设计 (基于 DeepAgent 风格)

## 设计目标

构建一个**半自主的 AI 工作流系统**,具备:
1. **深度推理** - 复杂任务的规划和决策
2. **工具使用** - 通过工具与世界交互
3. **多 Agent 协作** - 专业 Agent 分工协作
4. **记忆学习** - 从经验中持续进化
5. **人机协作** - 关键决策人机协同
6. **多端接入** - Telegram/Web/App 统一支持
7. **定时任务** - 周期性任务自动执行
8. **持续优化** - A/B 测试和数据驱动优化

## 支撑系统详细设计

### 1. Scheduler (定时任务系统)

```typescript
interface Scheduler {
  // 注册定时任务
  schedule(cron: string, handler: () => Promise<void>): ScheduledTask;

  // 注册一次性任务
  scheduleOnce(at: Date, handler: () => Promise<void>): ScheduledTask;

  // 取消任务
  cancel(taskId: string): void;

  // 暂停/恢复
  pause(taskId: string): void;
  resume(taskId: string): void;

  // 获取所有任务
  list(): ScheduledTask[];
}

// 周报定时任务示例
scheduler.schedule('0 20 * * 5', async () => {
  // 每周五晚上 8 点执行
  const report = await reportGenerator.generateWeeklyReport();
  await telegramBot.sendMessage(user.chatId, report);
});
```

### 2. Experiment System (A/B 测试系统)

```typescript
interface ExperimentSystem {
  // 创建实验
  createExperiment(config: ExperimentConfig): Experiment;

  // 分配变体
  getVariant(experimentId: string, userId: string): Variant;

  // 记录指标
  recordMetric(experimentId: string, userId: string, metric: string, value: number): void;

  // 获取结果
  getResults(experimentId: string): ExperimentResult;

  // 分析显著性
  analyzeSignificance(experimentId: string): SignificanceTest;
}

// 小红书标题 A/B 测试示例
const experiment = experimentSystem.createExperiment({
  name: '标题风格测试',
  variants: [
    { id: 'A', name: '亲切风格', template: '姐妹们！{topic}真的太好用啦～' },
    { id: 'B', name: '专业风格', template: '{topic}深度解析：{points}个关键要点' }
  ],
  metrics: ['click_rate', 'like_rate', 'comment_rate'],
  traffic_split: 0.5
});

// 发布时分配变体
const variant = experimentSystem.getVariant(experiment.id, post.id);
const title = variant.template.replace('{topic}', topic);

// 追踪效果
experimentSystem.recordMetric(experiment.id, post.id, 'click_rate', clicks / views);
```

### 3. Analytics System (数据分析系统)

```typescript
interface AnalyticsSystem {
  // 记录事件
  track(event: Event): void;

  // 查询指标
  query(metrics: string[], timeRange: TimeRange): MetricData[];

  // 聚合分析
  aggregate(metric: string, groupBy: string[]): AggregatedData;

  // 趋势分析
  trend(metric: string, period: Period): TrendAnalysis;

  // 相关性分析
  correlate(metricA: string, metricB: string): Correlation;
}

// 小红书运营数据分析
const analytics = await analyticsSystem.query(
  ['followers', 'views', 'likes', 'comments'],
  { start: lastWeek(), end: now() }
);

// 找出最佳发布时间
const bestTime = await analyticsSystem.aggregate('engagement', {
  groupBy: 'hour_of_day'
});
```

### 4. Report Generator (报告生成系统)

```typescript
interface ReportGenerator {
  // 生成报告
  generate(type: ReportType, config: ReportConfig): Promise<Report>;

  // 定时报告
  scheduleReport(type: ReportType, schedule: CronSchedule, recipients: string[]): void;

  // 导出报告
  export(report: Report, format: 'markdown' | 'pdf' | 'html'): Promise<Buffer>;
}

// 周报生成示例
const weeklyReport = await reportGenerator.generate('weekly', {
  period: { start: weekStart, end: weekEnd },
  sections: ['summary', 'tasks', 'metrics', 'learnings', 'plan'],
  includeCharts: true
});

// 发送给用户
await telegramBot.sendMessage(user.chatId, weeklyReport.markdown);
```

## 技术选型

| 层次 | 组件 | 技术选型 | 理由 |
|------|------|---------|------|
| **通信层** | WebSocket | `ws` | 轻量、成熟、TypeScript 支持好 |
| | REST API | `express` | 生态成熟、中间件丰富 |
| | 认证 | `jsonwebtoken` | JWT 标准、支持设备绑定 |
| **交互层** | 意图识别 | Claude Haiku | 快速、成本低 |
| | 对话框管理 | 自研 | 灵活定制 |
| **编排层** | 任务管理 | 自研 + SQLite | 轻量、无需额外服务 |
| **Agent 层** | LLM | Claude API | 最强推理能力 |
| | Agent 框架 | 自研 | 完全定制 |
| **能力层** | 浏览器 | Playwright | 功能强大、支持无头 |
| | 网络搜索 | SerpAPI/Tavily | 稳定、结果质量好 |
| **支撑系统** | 定时任务 | `node-cron` | 成熟、支持 cron 表达式 |
| | 实验系统 | 自研 | 定制化 A/B 测试 |
| | 数据分析 | 自研 + Chart.js | 可视化支持 |
| **记忆层** | 向量库 | Chroma | 本地部署、TypeScript SDK |
| | 数据库 | SQLite | 轻量、无需服务 |
| **前端** | Web UI | React + Vite | 快速开发、热更新 |
| | Mobile App | React Native | 跨平台、代码复用 |
