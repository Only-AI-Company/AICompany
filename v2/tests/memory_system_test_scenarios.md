# 记忆系统测试场景

## 测试目标

验证记忆系统在不同需求场景下：
1. **记忆检索**：能否找到相关历史任务和模式
2. **上下文增强**：enriched context 是否包含有用信息
3. **决策质量**：基于记忆的决策是否更准确
4. **记忆存储**：任务完成后是否正确存储

---

## 测试检查清单

### 每次测试后检查

- [ ] CEO 日志中是否显示"检索到 X 个相似历史任务"
- [ ] CEO 日志中是否显示"检索到 X 个相关模式"
- [ ] enriched context 是否包含历史记忆
- [ ] 决策是否考虑了历史经验
- [ ] TaskReviewer 是否存储了情景记忆
- [ ] TaskReviewer 是否提取了语义记忆

### 数据库检查

```sql
-- 检查情景记忆
SELECT id, task_description, status, created_at
FROM episodic_memories
ORDER BY created_at DESC
LIMIT 10;

-- 检查语义记忆
SELECT id, title, description, confidence, usage_count
FROM semantic_memories
ORDER BY confidence DESC
LIMIT 10;

-- 检查程序记忆
SELECT id, employee_id, task_type, version, is_active
FROM procedural_memories
ORDER BY version DESC
LIMIT 10;
```

## 预期结果对比

### 无记忆系统 vs 有记忆系统

| 场景 | 无记忆系统 | 有记忆系统 |
|------|------------|------------|
| 首次代码任务 | 分配给 CTO | 分配给 CTO |
| 第二次代码任务 | 分配给 CTO（无历史） | 分配给 CTO，**建议使用上次成功方法** |
| 代码优化 | 分配给 CTO | 分配给 CTO，**提供优化最佳实践** |
| 文案创作 | 分配给 CMO | 分配给 CMO，**参考历史成功文案** |
| 系统查询 | 直接返回状态 | 直接返回状态，**附带历史查询记录** |
| 外部信息 | 调用 HTTP 工具 | 调用 HTTP 工具，**记录搜索历史** |
